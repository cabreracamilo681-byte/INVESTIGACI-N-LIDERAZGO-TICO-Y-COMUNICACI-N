# INVESTIGACIÓN SOBRE LIDERAZGO ÉTICO Y COMUNICACIÓN DIRECTIVA
El presente repositorio contiene información, datos y código relacionado al proyecto de investigación titulado "Influencia del liderazgo ético en la efectividad de la comunicación directiva en Juntas de Acción Comunal ejecutoras de Obras con Saldo Pedagógico del IDPAC", presentado por Cristian Camilo Cabrera Zambrano, Yuddy Carolina Garzon Uribe, Paulo Cesar Grimaldo Pérez, Miguel Angel Orduz Largo, Cristian Camilo Tangarife Morales.


El repositorio contiene análisis de lenguaje natural (NPL) y Análisis de Datos Exploratorio (EDA), conteniendo modelos de regresión, visualizaciones interactivas y análisis descriptivo. 

Las bases de datos utilizadas, llamadas como  variables 'df' y 'df2' en el cuaderno de códigos también se encuentran en el repositorio.
